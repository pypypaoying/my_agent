## 二、回答你的三个疑问

### Q：`llm_client` 是哪来的？

我加的，**不是 Hello-Agents 教材要求的**。它是一层工程封装，目的只有一个：让全项目只有一个地方碰模型 API。

为什么值得单独一个文件：你 D3 要横向对比 DeepSeek / 通义 / 智谱的成本和效果，D10 要做分级路由（简单问题走小模型、难的走大模型）。如果调用代码散在十个文件里，换厂商就要改十处；有了这一层，只改 `.env` 里的两行。

### Q：它是项目代码，还是能力训练？

**两个都是，但要分清是哪条轨道。** 你的 Week1 里并行跑着两条线，我上次没讲清楚，这是你困惑的根源：

| | 轨道 A ｜手写地基 | 轨道 B ｜Agent 工程（本文件） |
|---|---|---|
| 内容 | micrograd → makemore → 手写 Transformer | llm_client → ReAct → 记忆 → RAG |
| 仓库 | `D:\llm-from-scratch` | `D:\mini-agent` |
| 训练什么 | 从第一性原理**推导**与实现 | **读懂、调通、改对、讲清** |
| 允许看资料吗 | ❌ 不允许，必须白纸推 | ✅ 允许，而且**必须**查 SDK 文档 |
| 验收方式 | 手写能跑 + 数值对齐 `gradcheck` | 跑通 + 有数字 + 面试讲得出来 |
| 简历上写成 | 「从零实现过 Transformer」 | 「不依赖框架手写过一个 Agent」 |

**轨道 B 的能力标准，从来不是「你能不能从零默写出来」。** 实习里没人让你默写。真实工作是：读文档 → 写 20 行 → 报错 → 读报错 → 改。它考的是这三个问题：

1. 你能不能说清 `arguments` 为什么可能是非法 JSON？
2. 厂商返回 400，你能不能定位到「是消息顺序错了」？
3. 让你加一个「失败自动降级到备用模型」的功能，你会改哪几行？

纯抄代码的人答不上来；**带着自己撞过的坑去读代码的人**答得上来。差别就在这里。

### Q：照抄就训练不到能力，怎么办？

你说得对，所以我改成了**四步阶梯**，原理是：

> **先自己撞墙，再读别人的解法。撞过墙之后读代码，效率是纯抄的十倍；没撞过就抄，效率是零。**

Part 4 的参考答案在文件最底部，前面有一道 STOP 横幅。它故意放在你**必须先撞完 4 个坑**才能到达的位置。

## 六、卡住怎么办（分级求助规则）

严格按顺序，每级最多花 10 分钟：

1. **读报错原文的最后 5 行**。90% 的情况直接告诉你哪个文件哪一行什么错。
2. **打印中间变量**。在怀疑的那一行前面加 `print(type(x), repr(x))`。`repr` 能看出「字符串 `"1"`」和「数字 `1`」的区别——这是 BUG 1 的本质。
3. **搜报错原文**（不要搜你的问题描述，搜报错本身）。
4. **查 `docs/notes/Python惯用法速补.md`**。如果是语法看不懂，那里有 3 行最小例子。
5. **缩小规模**。把 6 轮循环改成 1 轮，把 2 个工具改成 1 个。
6. **问我**。把这三样发给我：① 完整报错原文 ② 你已经试过的 2 种方法 ③ 你现在的猜测。

> ⛔ **禁止的做法**：卡住 3 分钟就直接翻 Part 4。这会让你产生「我看懂了」的错觉，而下午从零写 `day1_tool_call.py` 时会立刻暴露。
